# velvert-data-collecte

Dépôt de collecte de données — Vel'Vert (vélos électriques en libre-service).

## Contenu

- `script_collecte_velos.py` — script d'import des stations depuis l'export CSV vers la base de données
- `export_stations.csv` — exemple d'export hebdomadaire du système de stations
- `dictionnaire_donnees.md` — schéma de la table `stations`

## Pour démarrer

Voir `guide_setup_environnement.pdf`, fourni avec le brief *Environnement & Collecte*.
